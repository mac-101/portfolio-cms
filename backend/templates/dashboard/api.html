Good to know

  • The API is read-only. Edit your content here in the dashboard.
  • Only published projects are returned. Unpublished ones return 404.
  • List endpoints return count, next, previous and results, up to 50 per page.
  • If you change your slug in Settings, these URLs change too. Update your frontend if you do.
