Projects

Add projects without touching your frontend code.

Descriptions, images, technologies, and links, all managed from your dashboard. Your frontend just asks for the latest.

Publishing

Publish when you're ready.

Drafts stay private. Only published projects are returned by the API, so work in progress never leaks into your live portfolio.

publishing 
$ export API=https://your-domain.com/api/public/portfolios/your-slug

# published project
$ curl -i $API/projects/echonote/
HTTP/1.1 200 OK

# draft project
$ curl -i $API/projects/work-in-progress/
HTTP/1.1 404 Not Found
{ "detail": "Not found." }

Public API

Fetch the data. Render it your way.

Every portfolio gets a read-only JSON API with no API key. Use React, Next.js, Astro, plain HTML, or whatever you prefer.

The URL is a placeholder. Your own address appears in your dashboard.

portfolio.js 
// fetch your published projects
const res = await fetch(
  "https://your-domain.com/api/public/portfolios/your-slug/projects/"
);
const data = await res.json();

data.results.forEach((project) => {
  console.log(project.title, project.tech_stack);
});
